# VibeOffer — 24/7 Sales Agent Org

**Дата:** 2026-06-27
**Основано на:** «Hacking Sales» (Max Altschuler, 2015) + adversarially-проверенный research 2026
**Принцип:** агенты делают 80% (research, контент, драфты, аналитика, отчёты), человек делает 20% (одобряет, публикует где обязывает закон, решает стратегию).

---

## 0. Честная рамка (прочитать первым)

Запрос был «агенты продают 24/7, я занимаюсь продуктом». Это **возможно на 80%**, но не на 100% — и вот почему, по фактам из research:

1. **РФ-2026, реклама.** ФАС (25 марта 2026) признала **платную** рекламу в Telegram/YouTube нарушением ФЗ «О рекламе». Переходный период (без штрафов) — **до конца 2026**. Что **остаётся легальным**: свой канал, свой бот, инфо-посты о своём продукте, сбор заявок через бота. Что **запрещено**: платные интеграции/закупка рекламы в чужих каналах без ОРД-маркировки (ERID). → **Платные размещения обязан делать человек** (токен ERID привязан к рекламодателю-человеку).
2. **Платежи.** Принять деньги, выдать платную награду, оплатить посев — человек/система, не агент.
3. **Маркировка (ОРД/ЕРИР).** Любое платное размещение, даже самопиар, требует ERID. Это юридически человек.

**Вывод:** строим максимально автономную машину, где агенты генерят всё, что можно генерить, и человек тратит минуты на approve+публикацию, а не часы на создание. Это и есть «фаундер с агентами заменяет отдел».

## 1. Иерархия (кто кому подчинён)

```
                  ВЫ (founder) — стратегия, approve, публикация платного
                        │  получает 1 дайджест/день + сводку/неделю
                        ▼
            ┌─ Head-of-Growth Agent ─┐   оркестратор, cron 09:00 МСК
            │   диспетчит + собирает  │
            ▼            ▼            ▼            ▼
      Marketer     Growth-Channel  Referral-Loop  Sales-Ops
      Agent        Agent           Agent          Agent
      (контент)    (рекламщик)     (продавец)     (репортинг)
        │              │              │              │
        └──────────────┴──── всё на approve ────────┘
```

Все 5 агентов **зарегистрированы в коде**: `apps/web/lib/agents/registry.ts`. Мозг — наш Agent OS на Anthropic Messages API. 24/7-планировщик — **n8n self-hosted** (см. §5).

## 2. Роли и КОНКРЕТНЫЕ задачи (daily / weekly)

### 2.1. Head-of-Growth Agent (оркестратор, L4)
**Ежедневно 09:00:** прочитать вчерашние метрики → приоритет дня по правилу `blended CAC ≤ ₽300-500` (LTV junior ≈ ₽600-1000) → раздать задачи 4 суб-агентам → собрать их черновики в ОДИН дайджест founder'у:
```
[Сделано автономно]  — что агенты уже сгенерили
[Требует approve]    — что и почему + cost ₽
[Метрики + 1 вывод]  — воронка вчера
[Риск дня]
```
**НЕ делает:** не тратит бюджет, не публикует в чужих каналах, не меняет цену.

### 2.2. Marketer Agent (контент-движок, L2)
- **Ежедневно:** 1-2 поста для своего TG-канала («разбор junior-вакансии», «3 ошибки в резюме», «как пройти скрининг»). Тон peer, не HR-канцелярит.
- **Еженедельно:** 1 AEO-статья под цитирование в ChatGPT/Perplexity (формат: прямой ответ 40-60 слов сразу после заголовка → контекст → список). Темы из реальных hh-данных: «как junior пройти собес на [роль] 2026», «зарплата junior [роль] в [город]».
- **Еженедельно:** 1 идея free-tool (ATS-чекер резюме / «оцени шансы») — ранжируется + цитируется LLM + даёт PQL.

### 2.3. Growth-Channel Agent (рекламщик, L2)
- **Еженедельно:** research 3-5 нишевых TG-каналов о работе (аудитория, CPV, fit, оценка CAC) → шорт-лист founder'у.
- **Еженедельно:** драфт питч-сообщений админам каналов + 5-10 Avito-объявлений под специальности + креативы (с UTM/промокодом и плейсхолдером `[ERID]`).
- **НЕ закупает, не платит, не размещает.** Платное в чужих каналах = только человек + ERID.

### 2.4. Referral-Loop Agent (продавец, L2) — **приоритет №1**
- **Триггерно** (Match нашёл топ-вакансию / CV-Coach улучшил резюме / «получил оффер»): сгенерить шэрабельный артефакт момента-победы со встроенной реф-ссылкой + копию реф-оффера «приведи друга — обоим +неделя Pro» (награда = своя подписка → **легально, без ОРД/сбора**).
- **Ежедневно:** найти PQL (юзеры с aha-моментом, но без оплаты) → персональный nudge на пэйвол.
- Цель: K-factor ≥ 0.3 (это единственный канал с CAC ниже ₽99).

### 2.5. Sales-Ops Agent (репортинг, L4)
- **Ежедневно (вечер):** воронка дня — касания(UTM)→waitlist→signup→активация(скан)→paid→refund + CAC по каналу.
- **Еженедельно (пятница):** сводка + сравнение с прошлой + 3 вывода (сработало / нет / 1 фокус).
- **Алерты:** refund > 25%, CAC канала > ₽800, активация < 40%.

## 4. Каналы под RU B2C (приоритезированно, бюджет ~₽16k/мес)

**Жёсткое правило экономики:** LTV junior ≈ ₽600-1000 (высокий churn после трудоустройства) → целевой blended CAC ≤ ₽300-500.

### Tier 1 — запускать сразу (CAC ниже первого платежа)
1. **Реферальный цикл в продукте** (₽0, награда = своя подписка). Единственный канал, масштабируемый без burn. K-factor ≥ 0.3.
2. **Свой TG-канал + контент-агент** (₽0-3k). Главный канал аудитории, легальная органика.
3. **Avito** (₽2-4k) — самый дешёвый платный трафик РФ (CPC ₽2-5), junior физически сидят на Avito Работа.

### Tier 2 — при первых сходящихся метриках
4. **TG-посевы в нишевых каналах о работе** (₽5-8k) — переиспользует Growth-Channel Agent. **Обязательна ОРД-маркировка.**
5. **Микро-инфлюенсеры** (бартер—₽10k) — карьерные/студенческие блогеры, лучше на бартер (подписка + % рефералки).

### Tier 3 — органический PR (медленно, дёшево, для бренда)
6. **VC.ru** (от ₽500) + **Habr** (органика, технический нарратив про Agent OS — tech-junior отлично конвертит).

### Tier 4 — отложить
- **Яндекс.Директ** (CAC легко > ₽1500), **Telegram Ads** (порог €500 > месячного burn), **VK таргет**, **Дзен**.

### Стартовая раскладка ₽16k/мес
```
Рефералка (награды)        ₽3-4k
Avito (объявления)         ₽3-4k
TG-посевы (1-2 канала)     ₽5-6k
Резерв микро-инфлюенсер    ₽2-3k
Контент/автоматизация      ₽0-1k  (своя Agent OS, не платные SMM-сервисы)
```
Всё платное — только через реф-промокоды/UTM для честного замера CAC.

## 6. Что взято из «Hacking Sales» и что заменено

**Вечнозелёное (берём):**
- «Process is science — мерь каждую стадию воронки» → Sales-Ops Agent + `agent_invocations`.
- «Персонализация > объём» → гиперперсональные драфты, не спам.
- «ICP перед каналом» → PQL-таргетинг (Match-скор как сигнал).
- «Автоматизируй рутину» → то, для чего Альтшулер нанимал VA, делает агент.
- «Always be hunting» + «проси реферал на закрытии» → Referral-Loop Agent.

**Устарело (заменено):**
- Cold email как главный канал → **growth loops + Telegram-органика** (cold email B2C в РФ нерелевантен + Gmail с ноября 2025 бунсит non-compliant).
- Линейная воронка «до close» → **loops** (деньги в рекуррентности + рефералке, не в одноразовом close).
- SDR→AE закрывает сделку → **self-serve + reverse trial** (₽99-299 не окупает живого продавца).
- Классический SEO → **AEO** (попадание в ответы ChatGPT/Perplexity).
